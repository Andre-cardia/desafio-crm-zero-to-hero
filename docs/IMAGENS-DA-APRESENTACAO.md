# Imagens da apresentação

O HTML incorpora três imagens originais produzidas com image generation. Elas são usadas como fundos cinematográficos nos momentos de abertura, planejamento e implementação.

- **Abertura:** cidade de dados com conexões luminosas entre contatos e horizonte laranja; composição escura reservada para título.
- **Pré-projeto:** mesa de planejamento com wireframes holográficos de contato, pipeline, calendário e perfis.
- **Implementação:** pessoa desenvolvedora diante de uma rede de contatos, etapas de oportunidade e calendário.

As imagens não contêm marcas, nomes de clientes ou dados reais. A animação 3D independente desenha a rede de nós e conexões com Three.js.
