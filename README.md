# Desafio CRM — Mentoria Zero to Hero

**Repositório oficial:** https://github.com/Andre-cardia/desafio-crm-zero-to-hero

Projeto aplicado para transformar uma necessidade comercial em um CRM simples, funcional e demonstrável, usando BMAD para organizar planejamento e implementação.

## Como a atividade funciona

Há dois marcos de avaliação:

1. **Pré-projeto:** problema, usuários, fluxo, MVP e protótipo. Ainda sem construir o CRM.
2. **Projeto:** planejamento BMAD, implementação incremental do MVP, testes e demonstração.

## Uso pelo instrutor e pelos alunos

Este repositório é a **referência do desafio**. Cada aluno deve criar seu próprio repositório a partir dele, manter o trabalho privado durante a avaliação e compartilhar acesso com o instrutor. Assim cada entrega tem histórico, tarefas e revisões próprios.

Este repositório está habilitado como **Template repository**. O aluno seleciona **Use this template → Create a new repository**, escolhe um nome identificável, mantém sua cópia privada durante a avaliação e convida os dois mentores. O [cookbook](COOKBOOK-GITHUB.md) mostra cada clique, como enviar arquivos e onde os mentores registram a revisão e a nota.

Não inclua dados reais de clientes, senhas, chaves de API ou informações pessoais. Use somente dados de demonstração.

## Escopo resumido

O MVP acompanha contatos, oportunidades comerciais e atividades. Login e pelo menos dois perfis de acesso fazem parte do projeto. Painel, integração com e-mail, IA, importação de planilhas e outros extras são opcionais.

## Referência BMAD

O tutorial recomenda a versão estável do BMAD. A versão e os comandos podem mudar; confirme-os na [documentação oficial de instalação](https://docs.bmad-method.org/start/install-bmad/) antes da aula. A atividade não depende de uma stack específica.
